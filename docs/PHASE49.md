# Phase 49 — Branding and pending domains

A TEACH organization administrator can save a tenant-specific display name and primary hex color, and request a hostname. Domain requests are stored as **pending** with server-generated verification tokens and are never activated, resolved, exposed as public tenants, or routed by the Host header. No DNS TXT verification, TLS certificate provisioning, or custom domain traffic routing is implemented. Brand preferences are stored but not yet applied to every shared Blade layout. Names cannot be used to grant access. Tenant permissions remain solely `SchoolAccess` and `CampusAccess`. Actual production custom domain support requires DNS ownership verification, certificate automation, proxy allowlists, anti-takeover measures and cross-tenant hostname tests. Run `php artisan test --filter=Phase49SaasBrandingTest` and CI.
